## 2024-11-20 - Missing Focus Styles on Input Actions
**Learning:** Custom interactive elements like the chat's send/stop buttons often miss focus rings for keyboard navigation.
**Action:** When adding interactive elements or modifying buttons in this Tailwind CSS application, the standard focus indicator classes to use are `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2`.
